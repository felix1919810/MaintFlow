## 练2单价口径

来源：用户课件第02章“人力成本”、calcLabor函数、prac2验收清单与dl-p2模板，以及用户上传的练2测算器导出。课件其余模型/服务器/ROI练习仅作为后续要求，未套用其中价格作实时报价。

月薪22000×综合系数1.55=月综合成本34100元；34100÷21.75÷80%=1959.7701149元/人天。内部人天成本先保留2位为1959.77；对外人天按未舍入公式×1.25后取整为2450。25%是成本加成，不是25%毛利；未舍入理论毛利为20%。所有项目总额用明确列示的成本/售价分别乘人天，最终保留到分，不混用两种单价。

为降低角色薪资假设数量，本次统一用FDE复合交付角色单价，不冒充不同专业岗位的真实薪资。数据准备另用独立人员8人天×1500元，保留练1既有假设，不计进FDE31.2人天。
