# 设备点检与维修协同 · 业务核对助手

核对海岳机电的本次事件、来源与交接条件。

## 运行

需要 Node.js 22 或以上，无第三方依赖，无需 npm install。

```powershell
node server.mjs
# 打开 http://127.0.0.1:4180
node --test demo.test.mjs
```

## 文件

- index.html / style.css：产品界面。
- app.js：交互、结果、来源、执行轨迹与评估页。
- runtime.js：明确分工的规则/工具编排及合成样本。独立源码包默认离线；训练平台另外提供服务端DeepSeek在线起草，密钥不随包分发。
- project.json：项目、当前练习与集团模块范围。
- demo.test.mjs：正常及异常场景的可执行断言。
- server.mjs：仅在本机监听的独立预览服务。

## 输入与输出

输入：样本编号、演示身份、业务任务、异常场景、当前选用模块。

输出：核对结果、可定位合成来源、处理步骤、人工确认事项。

## 演示与真实实施

只处理本场景的合成资料；具体业务规则、真实接口和验收条件仍需核实。数据和身份均为合成演练；界面中下拉选择身份不是生产鉴权。正式实现需验证服务端身份、权限与接口，接入真实来源；若接入模型，还需沿用结构化输出、工具边界、重复评估及人工审批。原训练平台的完整原型和真实模型评估入口继续保留。
